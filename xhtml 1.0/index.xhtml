Wszystkie oficjalne znaczniki w XHTML 1.0

Znaczniki w XHTML zapisuje się, zaczynając od <, następnie nazwa znacznika, a na końcu >. Do niektórych znaczników można dodać też atrybuty, wtedy zaczyna się od <, potem nazwa znacznika, potem atrybuty i ich wartości np. href="link" itp. a na końcu >.

<!DOCTYPE>

<!DOCTYPE> - to znacznik deklaracji wersji języka XHTML, który został zachowany od wersji HTML 2.0.

Oto, jak należy go wpisać w XHTML 1.0:

<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Strict//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-strict.dtd">

Znaczniki struktury dokumentu

Znaczniki HTML 1, które zostały zachowane w XHTML 1.0

  • <html> - Otwiera dokument HTML. Wszystko, co widać i to, czego nie widać, musi być w środku.
    Atrybuty:
    lang - wybór języka strony (np. pl)
    dir - wybór kierunku tekstu (ltr lub rtl)
    W XHTML 1.0 stosuje się:
    <head lang="pl" xml:lang="pl" xmlns="http://www.w3.org/1999/xhtml"></head>
  • <head> - Sekcja nagłówka. Tutaj umieszczamy informacje dla przeglądarki, które użytkownik zobaczy tylko pośrednio.
  • <body> - ostatni znacznik struktury, odpowiada za zawartość która wyświetla się na stronie, czyli to co widzi użytkownik.

Znaczniki głowy (<head>)

Znaczniki zachowane z HTML 4.01

  • <link> - Połączenie HTML z zewnętrznymi zasobami, np. CSS, favicon.
  • <meta> - Metadane dokumentu, wartości wewnętrzne nie pobierane z poza pliku.
  • <title> - Tytuł strony. wyświetlany w pasku przeglądarki lub na liście stron.
  • <script> - skrypt, można dodać i w <body> i w <head>.
  • <style> - Wewnętrzny arkusz stylu.
    Atrybuty style: type - deklaracja typu stylu (np.type="text/css")
    media - określa urządzenie dla którego obowiązuje styl.
  • <base> - określa bazowy URL dla linków względnych.

Akapity, tekst i jego wyróżnienie

Znaczniki zachowane z HTML 1

  1. <p> - Akapit - podstawa każdego dokumentu tekstowego.
  2. <pre> - Tekst preformatowany - zachowuje wszystkie znaki białe (spacje i nowe linie), idealny do kodów i diagramów ASCII.
  3. <address> - Informacje o autorze.

Przykładowe użycie <pre> do diagramu ASCII:

         ________
        /       /|
       /       / |
      /       /  |
     |-------|   /
     |       |  /
     |       | /
     |-------|/

Znaczniki zachowane z HTML 2.0

  1. <em> - Tekst wyróżniony, zwykle pokazywany w kursywie.
  2. <strong> - Mocniejsze wyróżnienie tekstu, zwykle generowane jako pogrubienie.
  3. <code> - Służy do zaznaczenia fragmentów kodu.
  4. <samp> - Dane wyjściowe programu (output).
  5. <kbd> - Dane wejściowe.
  6. <var> - zmienna programistyczna lub matematyczna.

Znaczniki zachowane z HTMl 4.01

  • <abbr> - skrót
  • <acronym> - akronim
  • <dfn> - definicja terminu.
  • <del> - oznaczenie usuniętego tekstu.
  • <ins> - oznaczenie dodanego tekstu.

Linki i hiperłącza

  1. <a> - hiperłącze (odnośnik), odnośnik do innej strony.
    Przykład odnośnik do elementu na stronie:
    W jednym miejscu tworzymy element, o atrybucie id="nazwa", w innym miejscu tworzymy <a href="#id">.
    Żeby wszystko działało poprawnie trzeba id i href nadać te same wartości, tyle że w href, należy dodać # na początku (href="#id").
    Przykład odnośnik do elementu poza stroną:
    Kopiujemy link wybranej strony i wstawiamy go do atrybutu href.
    <a href="link">

Formularze i pola formularzy

Znaczniki formularzy

Znaczniki zachowane od HTML 2.0
  1. <form> - formularz, pozostałe znaczniki formularza muszą się w nim znajdować, aby wszystko działało poprawnie.
    Atrybuty:
    action - URL, na który są wysyłane dane formularza.
    method - wybór metody przesyłu (GET lub POST).
  2. <input/> - pole formularza, jego zadanie jest zależne od podanej wartości atrybutu type.
    Najważniejszym atrybutem <input/> jest type, mający parę wartości, które są bardzo potrzebne, aby zadeklarować działanie pola.
    Wartości type:
Zachowane z HTML 2.0
text
Jednolinijkowe pole tekstowe.
password
Jednolinijkowe pole tekstowe, z tą różnicą, że jest przeznaczone na hasło, z tego powodu wartość jest ukryta wizualnie, aby nie mogły jej zobaczyć osoby niepożądane.
checkbox
Pole wyboru, które może zaznaczyć i odznaczyć. Pozwala na wybór jednej lub wielu opcji.
radio
Przycisk radiowy, wartość ta wzięła swoją nazwę od odbiorników radiowych, ponieważ korzystając z radia, również idzie wybrać tylko jedną stację na raz, a naciśnięcie jednego przycisku powoduje wyłączenie poprzedniego.
Jak działa?
Jeżeli stworzymy dwa przyciski <input type="radio"/> i nadamy im tego samego name, to będzie można wybrać tylko jeden z nich, a po kliknięciu w drugi pierwszy się wyłączy, oczywiście tak samo działa to po dodaniu większej ilości radio button'ów.
submit
Przycisk wysyłający formularz, a następnie zostaje wyświetlony wynik przesłany przez serwer.
reset
Przywraca pola do ich domyślnych wartości.

Nowe atrybuty OGÓLNE

Pozostały atrybuty ogólne z HTML 4.01, które można zastosować do prawie każdego elementu strony m.in:

  • id - identyfikator elementu, każdy musi być indywidualny. Pozwala na przypisywanie elementom właściwości (np. stylu).
  • class - klasa wspólna elementów, można nadać ją kilku elementom jednocześnie i przypisać im te same właściwości (np.styl).
  • style - pozwala przypisać styl bezpośrednio do elementu w XHTML.
  • title - tekst wyświetlający się po najechaniu na element.
  • lang - wybór języka strony (np. pl)
  • dir - wybór kierunku tekstu (ltr lub rtl)

lang i dir mogą być stosowane do większości znaczników, przydaje się to w przypadku kiedy chcemy zacytować tekst w innym języku.
