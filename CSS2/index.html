Opcje zachowane z CSS level 1

Podstawowa składnia w CSS level 1

            selector{
               właściwość: wartość;
            }

Przykład:

            
            body{
               color: blue;
            }

W tym przykładzie ustawiam kolor napisów na niebieski.

Typy selektorów W CSS level 2

  1. Selektory typu - odnoszą się do elementów języka HTML, np. <body>.
  2. Selektory klasy - odnoszą się do elementów z atrybutem class, o konkretnej wartości.
  3. Selektory identyfikatora (id) - odnoszą się do elementów z atrybutem id, o podanej wartości.
  4. Selektory grupowe - kilka selektorów jednocześnie.
  5. Selektory potomków - odnoszą się do wybranych elementów, wewnątrz innych elementów.
  6. Selektor ogólny (*) - odnosi się do wszytskich elementów

Przykłady:

Selektor typu

            
               body{
                  color: blue;
               }

Selektor klasy

            
               .klasa1{
                  color: blue;
               }

Selektor identyfikatora

            
               #id1{
                  color: blue;
               }

Selektor grupowy

            
               .klasa1, #id1, body{
                  color: blue;
               }

Selektor potomka

            
               .klasa1 h1{
                  color: blue;
               }

Właściwości tekstu

  • color - ustawienie koloru tekstu.
  • font-family - wybór rodziny czcionek (np. Arial, Verdana, serif).
  • font-size - rozmiar tekstu, wyrażany w pikselach, procentach (np. 12px, 80%) lub słownie, xx-small (bardzo mały), x-small (mały), small (lekko mniejszy niż normalny), medium (domyślny), large (trochę większy niż normalny), x-large (duży) i xx-large (bardzo duży).
  • font-style - styl tekstu, np. pochylony, do jego wartości należą normal, italic i oblique.
  • font-weight - grubość tekstu, do wyboru normal, bold, bolder i lighter lub wyrażona w wartościach numerycznych.
  • text-align - położenie tekstu, do wyboru left(po lewej), right(po prawej), center(na środku) i justify (rozłożenie po całej szerokości).
  • text-decoration - ozdobienie tekstu, do wartości należą none (żadne), underline (podkreślenie), overline(nadkreślenie), line-through (przekreślenie).
  • letter-spacing - przestrzeń między literami.
  • word-spacing - przestrzeń między słowami.
  • vertical-align - wyrównanie w pionie, do jego wartości należą top(góra), middle(środek), bottom (dół) i domyślne baseline.
    (Działa tylko dla elementów liniowych, a nie blokowych.)

Kolory i tła

  • background-color - kolor tła
  • background-image - obraz tła (np. background-image: url("tlo.jpg");)
  • background-repeat - rozciąganie zdjęcia jako tła elementu, jego wartości to repeat (powtarzanie w obu kierunkach), repeat-x (powtarza tylko poziomo), repeat-y (powtarza tylko pionowo), no-repeat (Wyświetlany tylko raz).
  • background-position - pozycja tła, do jego wartości należą top (góra), bottom (dół), left (lewo), right (prawo), center (środek).
    Maksymalnie przyjmuje dwie wartości, jedną w pionie i jedną w poziomie.

Obramowania te można ustawiać dla każdej strony inne wystarczy tylko, że między border, a właściwość (np. style, width) wstawicie kierunek, top, left, bottom lub right.

Listy

  • list-style-type - typ podpunktora, wartości to disc, circle, square, decimal, upper-roman, lower-roman.
  • list-style-image - obrazek jako podpunktor (np. list-style-image: url("podpunktor.jpg");)
  • list-style-position - położenie podpunktów, inside lub outside.

Przykład:

  • list-style-type
  • list-style-image, list-style-position

Marginesy, wypełnienia i rozmiary

  • margin - wielkość marginesu.
  • padding - wielkość wypełnienia (miejsce między krawędzią a treścią).
  • width - szerokość.
  • height - wysokość.

Dla padding i margin można ustawiać dla każdej strony inne wartości wystarczy tylko, że po padding/margin damy -kierunek (np. -top, -bottom, -left, -right).

Nowość w CSS level 2

Padding, margin, widht i height mogą mieć teraz wartość auto, czyli automatyczne ustawienie.

Media types

Umożliwia stosowanie różnych styli, dla różnych ekranów.

  1. @media all - Zastosowanie dla wszystkich ekranów (domyślnie).
  2. @media aural - Zastosowanie dla czytników ekranu.
  3. @media braille - Zastosowanie dla urządzeń brajlowskich.
  4. @media embossed - Zastosowanie dla drukarek brajlowskich.
  5. @media handheld - Zastosowanie dla urządzeń przenośnych.
  6. @media print - Zastosowanie dla drukarek.
  7. @media projection - Zastosowanie dla projektorów lub slajdów.
  8. @media screen - Zastosowanie dla ekranów komputerów i monitorów.
  9. @media tty - Zastosowanie dla terminali znakowych.
  10. @media tv - Zastosowanie dla telewizorów i podobnych wyświetlaczy.

Pozycjonowanie elementów

Wprowadzono opcje position

  • static - (domyślna) element układa się standardowo w dokumencie ignorując właściwości top, right, left i bottom.
  • relative - element przesuwa się względem swojego domyślnego położenia, biorąc pod uwage właściowści top, left, bottom i right.
  • absolute - usuwa się z przpływu dokumentu, więc nie koliduje z innymi elementami, jest ustawiany względem swojego porzodka na podstawie właściwości top, left, bottom i right.
  • fixed - pozycjonowanie względem okna przeglądarki, ignoruje przodków i nie przesuwa się przy scrollowaniu.

boder: wielkość (np.2px) typ(np.solid) kolor(np. black)

max/min wigth/height

CSS level 2 wprowadza możliwość nadania maxymalnej wielkości elementu. Co to oznacza?

Jeżeli przypiszemy jakiemuś elementowi width np. 100%, bo chcemy żeby był jak najbardziej zbliżony do tej wartości, ale jednoczesnie chcemy żeby nie przekraczał jakiejswartości, używamy max.

właściwości typu min/max mamy cztery:

  1. min-wigth - minimalna szerokość.
  2. max-wigth - maksymalna szerokość.
  3. min-height - minimalna wysokość.
  4. max-height - maksymalna wysokość.

Pseudo-elementy

CSS level 2 wprowadza pseudo-elementy, czyli elementy, które nie istnieja w html, ale css wyświetla je, służy do dodawania elementw dekoracyjnych

Do pseudo-elementów należą:

  • :before - tworzy element przed wybranym elementem.
  • :after - tworzy element za wybranym elementem.

Ich uzycie wygląda tak:

element :before{ Właściowości }

lub

element :after{ Właściwości }

Kontrola zawartości

CSS level 2 wprowadza możliwość dezycodowania co dzieje się z treścią gdy nie mieście się.

Aby to ustawić używamy:

Overflow - Określa co dzieje się z zawartością, gdy nie mieści się w boxie.

Do jego wartości należą:

  • visible - (domyślny) zawartość nie jest przycinana, ani przewijana, jest poprostu widoczna poza granicami elementu nadrzędnego.
  • hidden - wystająca zawartość, zostaje ukryta, nie można jej zobaczyć.
  • scroll - zawartość ma zawsze widoczne paski przwijania (pionowei/lub poziome).
  • auto - paski przewijania pojawiają się tylko gdy zawartość nie mieści się w boxie.
