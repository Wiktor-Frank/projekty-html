            </li>

            textarea - wieloliniowe pole tekstowe. <br>

            rows - liczba wierszy <br>
            cols - liczba kolumn

        </li>
        <li>
            select - lista rozwijana. <br>
            Atrybuty: <br>
            name - nazwa pola, dla identyfikacji. <br>
            size - liczba widocznych elementow <br>
            multiple - ilosc opcji jakie pozna zaznaczyc
        </li>
        <li>
            option - element listy select. <br>
            Atrybuty: <br>
            value - Wartosc elementu(nazwa, liczba itp.) <br>
            selected - czy jest domyslnie wybrany
        </li>
        <li>
            label - etykieta dla pol formularza. <br>
            Atrybut: <br>
            for - powiazanie etykiety z polem(for="name obiektu do kotrego przypisujemy label")

        </li>
        <li>fieldset - grupowanie elementow formularza.</li>
        <li>legend - tytul dla fieldset.</li>
