Strona o CSS level 1 - 1997 r.

Od teraz styl strony można oddzielić od jej treści, dzięki kaskadowym arkuszom stylów.

Takie działanie zapewnia przejrzystość kodu zarówno treści, ale i stylu.

Podstawowa składnia w CSS level 1

            selector{
               właściwość: wartość;
            }

Przykład:

            
            body{
               color: blue;
            }

W tym przykładzie ustawiam kolor napisów na niebieski.

Typy selektorów W CSS level 1

  1. Selektory typu - odnoszą się do elementów języka HTML, np. <body>.
  2. Selektory klasy - odnoszą się do elementów z atrybutem class, o konkretnej wartości.
  3. Selektory identyfikatora (id) - odnoszą się do elementów z atrybutem id, o podanej wartości.
  4. Selektory grupowe - kilka selektorów jednocześnie.
  5. Selektory potomków - odnoszą się do wybranych elementów, wewnątrz innych elementów.

Przykłady:

Selektor typu

            
               body{
                  color: blue;
               }

Selektor klasy

            
               .klasa1{
                  color: blue;
               }

Selektor identyfikatora

            
               #id1{
                  color: blue;
               }

Selektor grupowy

            
               .klasa1, #id1, body{
                  color: blue;
               }

Selektor potomka

            
               .klasa1 h1{
                  color: blue;
               }

Właściwości tekstu

  • color - ustawienie koloru tekstu.
  • font-family - wybór rodziny czcionek (np. Arial, Verdana, serif).
  • font-size - rozmiar tekstu, wyrażany w pikselach, procentach (np. 12px, 80%) lub słownie, xx-small (bardzo mały), x-small (mały), small (lekko mniejszy niż normalny), medium (domyślny), large (trochę większy niż normalny), x-large (duży) i xx-large (bardzo duży).
  • font-style - styl tekstu, np. pochylony, do jego wartości należą normal, italic i oblique.
  • font-weight - grubość tekstu, do wyboru normal, bold, bolder i lighter lub wyrażona w wartościach numerycznych.
  • text-align - położenie tekstu, do wyboru left(po lewej), right(po prawej), center(na środku) i justify (rozłożenie po całej szerokości).
  • text-decoration - ozdobienie tekstu, do wartości należą none (żadne), underline (podkreślenie), overline(nadkreślenie), line-through (przekreślenie).
  • letter-spacing - przestrzeń między literami.
  • word-spacing - przestrzeń między słowami.
  • vertical-align - wyrównanie w pionie, do jego wartości należą top(góra), middle(środek), bottom (dół) i domyślne baseline.
    (Działa tylko dla elementów liniowych, a nie blokowych.)

Kolory i tła

  • background-color - kolor tła
  • background-image - obraz tła (np. background-image: url("tlo.jpg");)
  • background-repeat - rozciąganie zdjęcia jako tła elementu, jego wartości to repeat (powtarzanie w obu kierunkach), repeat-x (powtarza tylko poziomo), repeat-y (powtarza tylko pionowo), no-repeat (Wyświetlany tylko raz).
  • background-position - pozycja tła, do jego wartości należą top (góra), bottom (dół), left (lewo), right (prawo), center (środek).
    Maksymalnie przyjmuje dwie wartości, jedną w pionie i jedną w poziomie.

Ramki i obramowania

  • border-width - grubość, wartości to thin, medium, thick lub wartość wyrażona w pikselach.
  • border-style - style ramki, wartości to none, solid, dashed, double.
  • border-color - kolor ramki.

Obramowania te można ustawiać dla każdej strony inne wystarczy tylko, że między border, a właściwość (np. style, width) wstawicie kierunek, top, left, bottom lub right.

Marginesy, wypełnienia i rozmiary

  • margin - wielkość marginesu.
  • padding - wielkość wypełnienia (miejsce między krawędzią a treścią).
  • width - szerokość.
  • height - wysokość.

Dla padding i margin można ustawiać dla każdej strony inne wartości wystarczy tylko, że po padding/margin damy -kierunek (np. -top, -bottom, -left, -right).

Listy

  • list-style-type - typ podpunktora, wartości to disc, circle, square, decimal, upper-roman, lower-roman.
  • list-style-image - obrazek jako podpunktor (np. list-style-image: url("podpunktor.jpg");)
  • list-style-position - położenie podpunktów, inside lub outside.

Przykład:

  • list-style-type
  • list-style-image, list-style-position

Priorytet stylów

  1. styl jako bezpośredni atrybut znacznika.
  2. styl z arkusza.
  3. styl dziedziczony
