HTML

Historia powstania języka HTML oraz ogólny opis jego dziłania

HTML (ang. HyperText Markup Language) to język znaczników służący do tworzenia dokumentów hipertekstowych. Umożliwia on definiowanie struktury oraz treści stron internetowych, takich jak nagłówki, akapity, odnośniki czy obrazy.

<!DOCTYPE html>

Deklaracja <!DOCTYPE html> określa wersję języka html z której będziemy korzystać.
Obecnie wykorzystywana jest wersja HTML5, natomiast można korzystać również z starszych wersji, między innymi z HTML 4.01.

Aby użyć HTML5 należy umieścić deklaracje <!DOCTYPE html> na samym początku kodu, przed znacznikiem <html>

<html>

<html> jest standardowym znacznikiem w HTML, służącym do zaznaczenia przestrzeni, w której znajduje się kod.
